Farever Bench

Where is your Farever install?

The bench reads your own copy of the game every time it runs — the data for the numbers, the pak for the art. Nothing about the game ships with this app, so it needs the folder.

That is the folder holding Farever.exe and hlboot.dat — usually …\Steam\steamapps\common\Farever. You are asked once; it is remembered after that.
